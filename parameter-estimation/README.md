To run a full pass of the parameter-estimation project, first run `Attanasio Replication/Master File.r` inside the VDE and export the five aggregate CSVs: `attanasio_rev3_bridge.csv`, `mixture_probabilities.csv`, `mixture_means.csv`, `mixture_covariance_1.csv`, and `mixture_covariance_2.csv`. Put them together in `Attanasio Replication/VDE DelBoca Export`, or point `IEHC_ATTANASIO_OUTPUT_DIR` to another folder containing them. Then, from this folder, run `JULIA_NUM_THREADS=10 julia --project=. Del_Boca_Replication/Rev3_Substantive_Run.jl`. Rev3 reads the true production technology from the bridge, draws a fixed synthetic household sample from the exported Attanasio mixture, and runs two-stage SMM, threaded DX-NES, and adaptive Metropolis; it does not need the restricted NLSY file locally. The results are written to a new timestamped folder under `Del_Boca_Replication/substantive_output`, where `rev3_parameter_summary.csv` contains the two-stage parameter estimates, `rev3_empirical_moments.csv` contains the synthetic-data moments used in estimation, and `SUBSTANTIVE_RUN.txt`, the saved chain files, spreadsheets, and diagnostic figures record how the run was completed and what it produced.
