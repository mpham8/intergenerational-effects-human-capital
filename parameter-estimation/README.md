To run a full pass of the parameter-estimation project, start in this folder and run `JULIA_NUM_THREADS=10 julia --project=. Del_Boca_Replication/Rev3_Substantive_Run.jl`. This is the only command that needs to be started manually: the substantive-run file first runs `Attanasio Replication/Master File.r`, which estimates the three period-specific child human capital production functions and writes `attanasio_rev3_bridge.csv`, and then it loads that bridge into the Del Boca Rev3 code, constructs the empirical moments from the shared NLSY/CEX data, and runs the two-stage SMM, threaded DX-NES, and adaptive Metropolis estimation. The data file can be changed with `IEHC_NLSY_DATA_FILE`, which is useful when moving the project to the Windows VDE. The results are written to a new timestamped folder under `Del_Boca_Replication/substantive_output`; inside it, the `attanasio` folder contains the Attanasio estimates and bridge, `rev3_parameter_summary.csv` contains the first- and second-stage Del Boca parameter estimates, `rev3_empirical_moments.csv` contains the moments used in estimation, and `SUBSTANTIVE_RUN.txt`, the saved chain files, spreadsheets, and diagnostic figures record how the run was completed and what it produced.
